Главная находка этого прохода — **#65**. Сервис `farm-trader` хранил секретные ключи сессий открытым JSON на диске, а имя файла собиралось из непроверенной строки. Эти ключи — SPL-делегаты на ATA инструментов игроков: утечка папки означала кражу NFT, минуя игру.
