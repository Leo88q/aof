# Аудит лаборатории и интерфейса (2026-09-28)

Проверялись: вкладка «Лаборатория» (обзор + участок), мобильная адаптация игры
(320–430px) и сайта (360–1440px), живость полей обзора, картинки на участке и
перечень механик, которые ещё закрыты на цепи.

Всё, что помечено «исправлено», проверено в браузере (headless Chromium):
скриншоты на 320/390/768/1024/1440px, замер `document.scrollWidth` и обход
элементов, выходящих за вьюпорт. Аудит собран как одноразовый прогон, но часть
проверок закреплена в `frontend/tests/ui-regressions.test.ts` (`npm run test:ui`,
шаг CI «Frontend build»).

## 2. Почему в панели были именно Данные / Схема / Кремний

Это три базовых материала, которые производят три «добывающих» инструмента
(`GAME_INVENTORY.md`: `plasma_cutter → CIRCUIT`, `silicon_extractor → SILICON`,
`data_harvester → DATA`). На обзоре они стояли как витрина добычи, но:

- источник данных у панели был правильный (`/query/balances` — SPL-балансы),
  а вот список был куцый: 23 из 26 ресурсов не имели витрины в лаборатории;
- те же три ресурса дублировались в «Экономике».

**Решение:** панель стала «Ресурсами лаборатории» — 8 позиций производства
(Данные, Схема, Кремний + Энергопоток, Нейрон, Синапс, Сигнал, Модель), полный
список 26 — по ссылке «Все 26 →» в «Экономике», где базовые больше не вынесены
в отдельную категорию-дубль, а стоят в группе «Производство лаборатории».

## 3. SOL газ, Энергия, Стрик — что это и работает ли

| Показатель | Механика | Состояние |
|---|---|---|
| **Энергия** | `EnergyAccount` PDA: кап 20, +1 за 30 мин, списывается за посев (`ENERGY_COST_PLANT = 1`), сбор (`1`), переработку и тренировку (`2`) | **Работает.** Показывается `13/20` + полоса. До подключения кошелька — «—» (нет аккаунта) |
| **SOL газ** | `GasTank` PDA: `balance_micros` (1e6 = 1 SOL), `depositGas`/`withdrawGas`/`sweepGasFees`; списывается за `unstake`, `craft`, `reroll` | **Работает.** Раньше был литералом; теперь читается из цепи |
| **Стрик** | Отдельной канонической инструкции и индексатора нет: `/streaks/*` отвечает 503 | **Не работает.** Убран из обзора, чтобы не держать мёртвое поле |
| **Нагрузка сети** | `WeatherState` PDA (0 блэкаут / 1 номинал / 2 скачок / 3 френзи) → множитель накопления энергопотока на «Сетевой станции» | **Работает**, если PDA существует; иначе чип честно пишет «нет данных сети» |

## 4. Механики, которые ещё закрыты на цепи (fail-closed)

Обзор по коду бэкенда (39 ответов `503`): `hot_market`, `collectors`, `rebirth`,
`session keys`, `streaks`, `daily rewards`, `challenges/achievements`,
`comeback`, `referral tiers`, `guilds`, `vp/privileges`, `trust profile`,
`portfolio valuation`, `friend water`, `neighbors`, `npc`, `flask use`,
`energy exchange`, `bow reward`, `trader rules`, обмен энергии, ремонт
(если не заведены mint-адреса). Они перечислены в
`frontend/src/components/ui/FeatureDisabledNotice.tsx` и в `site/content/mechanics.ts`.

Что стоит доделать до продакшена (не сделано в этом заходе):

1. **Проверять 503 в интерфейсе раньше, чем рисовать элемент.** Сейчас часть
   экранов сначала показывает кнопку, а потом ошибку при нажатии.
2. **Эмодзи в тостах** (❌/✅/⏸️) на устройствах без emoji-шрифта превращаются в
   «тофу» — заменить на `ResourceGlyph`/`UI_ICONS`, как это уже сделано в шапках.
3. **Бандл 1.19 МБ** одним чанком: для мобильного LCP нужен code-split по вкладкам.
4. **Кошелёк**: поддержан только инжектируемый Phantom/Backpack; нет Wallet
   Standard и мобильных deep-link’ов — на телефоне подключение может не найтись.
5. **Добыча на участке** выключена флагом `VITE_MINING_ENABLED` — до включения
   участок остаётся витриной построек.
6. **Визуальные регрессии**: добавленный `frontend/tests/ui-regressions.test.ts`
   ловит только исходники; для верстки стоит подключить скриншот-тесты
   (Playwright) хотя бы на 390px и 1440px.

## 5. Как проверялось

- Headless Chromium (puppeteer-core), ширины 320/360/390/430/768/1024/1440,
  iPhone-подобный вьюпорт с `deviceScaleFactor: 2`.
- Скрипт обходит DOM, считает элементы, у которых `right > clientWidth` или
  `left < 0`, плюс элементы с `scrollWidth > clientWidth` без своего скролла.
- Отдельный прогон с фейковым Phantom-провайдером и подменёнными ответами API
  (балансы, газ-бак, энергия, погода, инвентарь) — чтобы проверить экраны в
  «наполненном» состоянии, а не только пустые.
- Итог после правок: горизонтального оверфлоу нет ни на одном экране
  (лаборатория, участок, экономика ×4, мастерская ×4, рынок, задания ×3, профиль),
  ни на одной проверенной ширине.
