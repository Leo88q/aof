## Что показывает тестовый стенд без бэкенда

В песочнице нет `.env.local`, Postgres и RPC, поэтому `/api/*` не отвечает. Это не
заглушка, а проверяемое поведение: каждая панель при отсутствии данных рисует честное
состояние («нет связи», «—», «недоступно из сети»), а не выдуманные числа — инвариант
закреплён тестами 9, 14, 15, 22. Подключение кошелька, транзакции и NFT требуют
развёрнутого `aof_backend` и RPC: их поднимают вместе со стендом (`VITE_API_URL`,
`VITE_RPC_URL`, `VITE_DEV_BACKEND_URL`).

## Что мешает выпустить релизную сборку

`npm run release:check` (он же — шаг `npm run build:release`) намеренно отказывает, пока
не заполнены данные оператора. Сейчас перечислено 14 полей — все они данные владельца,
а не код:

- `operatorName`, `operatorAddress`, `operatorCountry`, `registrationDetails`;
- `governingLaw`, `retentionPolicy`, `transferSafeguards`, `privacyRepresentative`;
- `contactEmail`, `privacyEmail`, `securityEmail` (реальные адреса);
- `canonicalOrigin` (проверенный HTTPS-домен без пути);
- `audienceCountries`, `processors` (проверенные списки).

Обычная сборка (`npm run build`) и тестовый стенд (`npm run preview`) от этих полей не
зависят — их можно показывать как есть.
