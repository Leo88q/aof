# Стенд сайта: фон и приборные окна (2026-09-30)

Задача владельца: «добавить сгенерированные картинки на фон сайта, а окошки
сделать более кастомными — с рубильниками и переключателями, как в игре».

Сделано в `frontend/`: сайт получил сцены на фон, пульт к ним и корпуса окон,
собранные по языку приборов из `frontend/src/theme/forge.css`.

## 1. Арт

Восемь картинок в `frontend/public/assets/site/` (1584×672 / 1408×768, JPEG):

| Файл | Что нарисовано | Где стоит |
|---|---|---|
| `hall.jpg` | Зал с рядами шкафов и пультом на переднем плане | `home`, `world`, `lore` |
| `console.jpg` | Лицевая панель: тумблеры, галетники, рубильник, лампы | `start`, `guide`, `glossary`, `docs`, `rules`, `faq`, `strategies` |
| `bay.jpg` | Рубильники вниз/вверх, шины, кабели | `energy`, `weather`, `manifesto`, `roadmap` |
| `forge.jpg` | Камера кузни со стеклом и разрядом | `craft`, `tools`, `mine`, `recipes` |
| `market.jpg` | Торговый зал с терминалами | `market`, `packs`, `lottery`, `economy`, `trade` |
| `vault.jpg` | Коридор хранилища | `quests`, `seasons`, `trust`, `investors`, `potato`, `resources` |
| `metal.jpg` | Текстура шлифованного графита | Кромка корпусов, пульт, режим «Металл» |
| `rail.jpg` | Ряд одинаковых приборных плит с лампами | Полоса над подвалом |

Правила арта: палитра A (графит, циан `#5FC9DA`, маджента-награда `#E0708A`),
ни одной буквы и цифры на картинке, низкий контраст, тёмные края — сцена не
спорит с текстом. Размеры подобраны так, чтобы страница не тяжелела: от 12 КБ
(`metal.jpg`) до 200 КБ (`bay.jpg`).

## 2. Как сцена попадает на страницу

- `src/site/content/scenery.ts` — таблица `маршрут → сцена` и путь к файлу.
  Ключи таблицы обязаны совпадать с деревом страниц: иначе сцена молча не
  доедет до игрока (это проверяет тест).
- `src/site/layout/SiteStand.tsx` — слой фона `.site-backdrop` (сцена, металл,
  сетка) и пульт `.site-deck`. Слой лежит на `z-index: -1` внутри оболочки с
  `isolation: isolate`, как игровая сцена вкладки: иначе он уходит за
  непрозрачный фон страницы.
- Заголовок страницы показывает ту же сцену в своём окне через переменную
  `--site-scene`, которую выставляет `Layout.tsx`.

## 3. Пульт и окна

`src/site/ui/Controls.tsx` — четыре прибора, все настоящие органы управления:

- **лампа** (`Lamp`) — состояние live / wait / off;
- **рубильник** (`Lever`) — кнопка с `role="switch"` и `aria-checked`;
- **галетник** (`Rocker`) — радиокнопки в `fieldset` с легендой;
- **фейдер** (`Fader`) — `input[type=range]` с подписью.

Пульт внизу страницы включает подсветку фона, выбирает слой (сцена / металл /
сетка) и меняет яркость. Он **ничего не читает из сети и ничего не обещает**:
это оформление страницы, а не вторые показания рядом с игрой. Кошелёк для
пульта не нужен, настройки живут только в состоянии вкладки (без хранилища).

Окна сайта собираются как лицевые панели: корпус с безелем, стекло с винтами
по углам, гравированная табличка с лампой над заголовком, линейка с рисками под
героем. Заголовок витрины на главной — галетник: выбранный экран горит, два
других уходят в тень.

## 4. Как проверить

```bash
cd frontend
npm run dev          # сайт: http://localhost:3000/site/home
npm run test:ui      # 4 новых теста: сцены, пульт, панели, семь языков
npm run build
```

Тесты (`tests/ui-regressions.test.ts`) держат: наличие файлов сцен и совпадение
таблицы с деревом страниц; отсутствие игровых данных в пульте; приборы на
настоящих элементах управления; лампы, винты, фейдер и галетник в слое;
подписи пульта на всех семи языках.

## 5. Замена арта

1. Держать пропорцию 2:1 или 16:9 и ширину 1400–1600 px, JPEG ≤ 250 КБ.
2. Класть файл в `frontend/public/assets/site/`.
3. `public/_headers` отдаёт `/assets/*` как `immutable` на год — при замене
   картинки под тем же именем **переименуй файл**, иначе браузер отдаст старую.

## 6. Реестр инструментов (дополнено 2026-09-30)

Жалоба владельца: «в инструментах не показаны все инструменты и как-то всё
хаотично». Страница `/site/tools` перестроена в четыре читаемых блока:

1. **Реестр** — таблица всех пяти типов: инструмент (картина), добываемый
   ресурс (значок), часы захода `8 / 12 / 14 / 20 / 20`, множитель выхода
   `×1.00 … ×1.80`, источник (капсулы дропа / только сборка).
2. **Профили** — карточка на каждый тип: картина, одна фраза о смысле
   инструмента и те же рабочие числа списком.
3. **Редкости** — пять характеров с картинами и подписями плюс матрица
   «редкость → часы, множитель».
4. **Витрина** — все 25 исполнений (`5 типов × 5 редкостей`) с фильтром по
   редкости и счётчиком показанного.

Числа не выдуманы: они лежат в `src/i18n/siteToolsCatalog.ts`
(`TOOL_SHIFT_HOURS`, `TOOL_YIELD_MULTIPLIER`, `TOOL_RESOURCE`, `TOOL_FROM_PACK`)
и сверяются с `GAME_INVENTORY.md` и `aof-core`. Подписи переведены на семь
языков сайта; тест проверяет, что ни один тип не остался без описания.
Добыча по-прежнему приостановлена: на странице стоит честная оговорка, что
таблица описывает правила программы, а не доступное действие.

## 7. Каталог ресурсов по отделам

Жалоба владельца: «раздел с ресурсами расскажи о всех ресурсах и покажи все
ресурсы там в отделе с ресурсами». `/site/resources` теперь раскладывает все
27 ресурсов по отделам (`base`, `chain`, `material`, `rare`, `consumable`,
`token`, `collab`, `social`) в порядке цепочки:

- заголовок отдела — панель с лампой, названием и счётчиком `показано / всего`;
- пояснение отдела одной фразой (зачем этот ряд в производстве);
- карточка ресурса: картина, статус, название, описание, марки роли
  («Собирается по рецептам: N», «Расходуется в рецептах: N») и строка связей.

Роли считаются из `WORKSHOP_RECIPES`, а не пишутся в разметке. Поиск и фильтр
отдела сохранены; счётчик «Показаны все 27 ресурсов» меняется на «Показано N
из 27», когда ряд сужен. Пустые отделы не рисуются: пустой раздел читался как
поломка поиска.

## 8. Один фон у всей полки

Разные оттенки подложек у инструментов и ресурсов — это дефект выравнивания, а
не оформление. Что было и что сделано:

- `scripts/normalize-art-backgrounds.mjs` читал только `public/assets/nfts` без
  вложенной папки — 28 картин ресурсов не мерялись никогда;
- допуск `TOLERANCE = 10` пропускал подложку с синим уклоном (+10 по синему):
  инструменты стояли на `7,14,30`, ресурсы — на `2,9,20`;
- обход сделан рекурсивным, допуск снижен до `6`, все 53 картины приведены к
  плитке интерфейса `#0D1013` (той же, что фон плашки `.nf-plate`).

Файлы после выравнивания пересжаты (JPEG q86, mozjpeg): полка NFT стала легче
на 13%, самый крупный файл — 198 КБ. `npm run art:check` теперь проверяет обе
папки и падает, если оттенок снова разъехался.
